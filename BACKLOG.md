## Rules for picking the next one

1. Prefer a role whose absence costs a founder time every week.
2. Never ship two employees whose trigger phrases collide - if they would fight over the same request, the second one routes through the first.
3. If a role needs a tool the user has not connected, ship it anyway with the tool listed under *Tools it assumes*, and say so plainly.
