# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Style owner / brand lead> | The twenty decisions, exceptions | | Decides contested rules once, not per document |
| <Author / document owner> | Queries, accept or reject | | Prefers numbered queries at the line |
| <Legal reviewer> | Contracts, policies, citations | | Overrides the sheet; record the override |
| <Compliance or regulator contact> | Form-governed documents | | The form's template wins over house style |
| <Designer> | Typography, layout, alt text | | Copy fixes stop where layout begins |
| <Translator> | Localised versions | | Send the ledger, not just the document |
| <Client contact> | Client-supplied templates and their rules | | Their brand governs their document |

## Rules

- Record who sends PDFs and needs a converted file; it changes the estimate every time.
- Note who accepts changes without reading them; their documents need a second proof.
- Never store client document content or customer names here.
