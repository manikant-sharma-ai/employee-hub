# journal.schema - shape only, no days recorded

One file per month, `notes/journal/YYYY-MM.md`. One bullet per review, written before the reply.

```
- **YYYY-MM-DD** - <scope reviewed> | <annualised spend, identified saving, realised saving> |
  <what the next review should do differently, or "nothing">
```

## Rules

| Field | Requirement |
|---|---|
| Date | dd/mm/yyyy |
| Scope | What was reviewed, and what was not |
| Numbers | Annualised spend and the saving, in one currency |
| Next time | A change in method, or "nothing" |

## What does not belong here

- Vendor contract terms, invoices or credentials.
- A repeat of the cut list. That belongs with the pack.
