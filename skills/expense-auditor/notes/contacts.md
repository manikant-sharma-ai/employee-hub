# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Founder / audit requester> | Scope, threshold, escalation, approval of the policy fix | | Agree the threshold in writing before the sweep starts |
| <Accounts person> | Ledger export, payment references, vendor masters | | Ask for the raw export, not a formatted report |
| <CA> | GST credit eligibility, TDS sections and thresholds, reversal treatment | | Send the invoice with the question; never ask for an opinion without it |
| <Procurement owner> | PO, rate card, award record, three-way match | | The PO explains most rate variances |
| <Top vendors' accounts contacts> | Credit notes, revised invoices, statements | | Only after the founder approves the approach |
| <Bank relationship> | Charge reversals, standing instructions, UTR lookup | | Auto-debits are found here first |
| <HR / payroll> | Employee bank details, advance records, exit status | | Verify any changed bank account by phone |
| <SaaS or tool owner, per subscription> | Seat counts, usage, renewal decision | | Every subscription needs a named owner |
| <Lawyer> | Anything that turns into a recovery dispute or a conduct question | | Not this role's call to make |
