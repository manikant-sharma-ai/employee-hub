# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Amazon category manager / account manager> | Category approvals, fee changes, suppression appeals | | Ask for the rule in writing before relying on it |
| <Flipkart seller support contact> | Listing issues, F-Assured, returns disputes | | Ticket numbers, always |
| <IndiaMART account manager> | Catalogue, lead credits, response rate | | Lead quality matters more than lead count |
| <GeM seller helpdesk> | Catalogue, bid eligibility, EMD | | Confirm eligibility before bidding, not after |
| <Graphic designer / photographer> | Image stack, infographics, A+ modules | | Send the shot list, not a mood board |
| <Packaging printer> | Label artwork, declarations, MRP printing | | A label mismatch with the listing is a return |
| <CA or compliance consultant> | Licences, HSN and GST, legal metrology | | Confirm the rule; never assume it |
| <FSSAI / BIS / state licensing consultant> | Category licences and renewals | | Track expiry dates in one sheet |
| <Warehouse or 3PL> | Stock available, dispatch SLA, packaging | | A listing that oversells damages account health |
| <Pricing or finance owner> | Landed cost, fee reconciliation, settlement | | Reconcile the settlement against the sheet monthly |
