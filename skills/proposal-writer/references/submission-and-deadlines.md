# Submission and deadlines

A perfect proposal submitted at 15:01 for a 15:00 deadline does not exist. This file is the
last mile, and it is where bids are lost to things that have nothing to do with quality.

## The submission instructions, read first

Before writing a word, extract these into a checklist:

| Item | Why it disqualifies |
|---|---|
| Deadline, date, time and timezone | Late is rejected, without exception |
| Channel - portal, email, physical | The wrong channel is not received |
| File format and naming convention | Unnamed or wrong-format files are rejected |
| Page limit and font or margin rules | Penalised or rejected |
| Number of copies, physical or digital | Short submission is incomplete |
| Signatures, stamps, authorisation letter | Unsigned is invalid |
| EMD amount, instrument and format | No EMD, no bid |
| Annexures and forms, by reference number | A missing form is an incomplete bid |
| Clarification deadline | After it, ambiguity is your risk |
| Validity period required | Shorter validity is non-responsive |

## The T-minus plan

| When | What |
|---|---|
| T-10 days | Requirements shredded, matrix built, clarifications issued |
| T-7 | Structure agreed, sections assigned, evidence pulled from the library |
| T-5 | First full draft; commercials in build-up |
| T-4 | Price approved; deviations register closed |
| T-3 | Red-team read against the matrix; gaps listed |
| T-2 | **Freeze.** No new content. Only fixes and formatting |
| T-1 | Final PDF, page count, bookmarks, checklist, EMD arranged |
| T-4 hours | Upload or dispatch; confirmation saved |
| T-2 hours | Buffer for a portal failure |

The T-2 freeze exists because the last 48 hours are for checking, not writing. Every bid
that is edited until the deadline is submitted with an unchecked page.

## The pre-submission checklist

```
FORMAT
[ ] Page count within the limit
[ ] Font, size and margins as specified
[ ] File format correct (PDF/A where asked)
[ ] File name exactly as instructed
[ ] Bookmarked and searchable

CONTENT
[ ] Every mandatory requirement answered, per the matrix
[ ] Deviations declared in the register
[ ] Executive summary present and under one page
[ ] Every claim has a proof point
[ ] Page numbers in the matrix match the document

ADMINISTRATIVE
[ ] All forms and annexures present, in the client's numbering
[ ] Signed and stamped where required
[ ] Authorisation letter or power of attorney attached
[ ] Certificates valid on the submission date
[ ] Financial statements for the required years
[ ] EMD instrument in the required format, valid through the required date

SUBMISSION
[ ] Uploaded or dispatched to the correct channel
[ ] Confirmation or acknowledgement saved to the bid folder
[ ] Copy of the submitted file archived, read-only
```

Two people run it. The person who wrote the bid does not run it alone.

## Portal mechanics

- **Register the bidder account early.** Verification can take days, and it is the
  commonest last-minute failure.
- **Upload a test file** if the portal allows, to learn the size limit and the naming rule.
- **Do not leave the upload to the final hour.** Portals slow down at deadlines, and every
  bidder in the country is on it.
- **Save the acknowledgement** - the reference number, the timestamp, the file hash where
  shown. It is the only proof of submission.
- **Physical submissions**: courier with tracking, receipt, and a photograph of the sealed
  envelope. Hand delivery gets a stamped acknowledgement.

## After submission

| Step | When |
|---|---|
| Note the reference number in `notes/journal` | Same day |
| Log the bid in the tracker with value and deadline for result | Same day |
| Prepare for the presentation or demo, if shortlisted | Immediately |
| Request the debrief on a loss | Within a week of the result |
| Record what scored and what did not | Within a week, in `notes/learnings.md` |

## When it goes wrong

| Failure | Recovery |
|---|---|
| Portal down at the deadline | Most portals publish a fallback; check the instructions before, not during |
| A form is missing | If the client allows post-submission submission of a form, ask immediately; otherwise withdraw and re-plan |
| Price error found after submission | Notify in writing before evaluation closes, with the correction; a silent correction is worse |
| EMD not arranged | The bid is non-responsive; do not submit a substitute instrument unless the client confirms it in writing |
| Bid lost on a technicality | Record it in `learnings.md` - the checklist exists for this reason |

## Anti-patterns

| Anti-pattern | Cost |
|---|---|
| Reading the instructions after drafting | Format non-compliance discovered at T-1 |
| One person writes and checks | The writer cannot see the gap |
| Uploading in the last hour | A portal timeout ends the bid |
| No acknowledgement saved | No proof of submission, and a dispute you cannot win |
| Editing after the freeze | An unchecked page in the final file |
| No debrief requested | The same mistake next quarter |
| Paper-only bid with no tracking | Lost in transit, and no evidence |
