# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Client procurement contact> | Clarifications, submission queries, results | | Record the exact wording of every clarification answer |
| <Technical evaluator, where known> | The criteria that actually decide the score | | Never contact directly outside the permitted channel |
| <Incumbent> | What is being defended, and at what price | | Public award data often names it |
| <Internal price approver> | Margin, discount, final number | | Approval recorded with date and number |
| <Operations or delivery lead> | Delivery dates and capability confirmed in writing | | Never promise a date they have not given |
| <Bank> | EMD, performance BG, advance BG, limit | | Charges are a real cost of bidding |
| <CA> | GST rate, TDS, MSME status, EMD accounting | | Ask before quoting a tax treatment |
| <Lawyer> | LD, indemnity, termination, contract terms | | This role responds; the lawyer reviews |
| <Reference clients> | Contactable references with permission | | Confirm permission before every bid that names them |
| <Tender portal helpdesk> | Account verification, upload failures, size limits | | Register early; verification takes days |
