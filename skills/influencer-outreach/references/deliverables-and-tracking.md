# Deliverables and tracking

The campaign is not the negotiation. It is the twelve rows in a sheet, each one
moving from briefed to paid.

## The tracker, one row per deliverable

| Column | Example |
|---|---|
| Creator / handle | @thekitchenco, Priya Nair |
| Tier | Micro |
| Fee (₹) | 18,000 |
| Deliverables | 1 reel + 3 stories |
| Brief sent | 02 Nov |
| Draft due / received | 05 Nov / 05 Nov |
| Approved | 06 Nov |
| Live date + link | 07 Nov, link |
| Screenshot | Yes |
| Views 48 h | 61,400 |
| Saves / shares | 1,240 / 310 |
| Code redemptions | 22 |
| Attributed revenue (₹) | 26,400 |
| Cost per order (₹) | 818 |
| Rights | Organic 12 m + paid 90 d |
| Payment status | Invoice received, TDS noted, paid 12 Nov |

## The three failures this sheet prevents

1. **The creator who goes quiet.** Every row has a next date. A row with no movement for four days gets one polite message, then a call, then a decision.
2. **The payment with no proof.** Payment triggers on live link plus screenshot, written in the brief.
3. **The campaign nobody can evaluate.** Codes and links are the only bridge between a view and an order.

## Attribution that survives scrutiny

| Mechanism | Strength | Weakness |
|---|---|---|
| Unique discount code | Strong, works offline in DMs | Misses full-price buyers |
| Unique UTM link | Good for web traffic | Lost in app browsers |
| Postback or affiliate link | Strongest, order-level | Needs setup before the campaign |
| Ask-at-checkout "where did you hear" | Fills the gap | Self-reported, unreliable |
| Nothing | — | The default failure |

Use a code **and** a link. Report the attributed number, then state the
unattributable share as a range, not as zero.

## Reading the 48-hour numbers honestly

| Metric | What it means | What it does not mean |
|---|---|---|
| Views | Distribution | That anyone wanted the product |
| Saves | Intent to return | Purchase |
| Shares | The message travelled | Sales |
| Comments asking for the link | Real demand signal | That they bought |
| Code redemptions | Attributed orders | Total effect |
| Story link taps | Curiosity | Conversion |

Judge a creator on cost per attributed order, and on whether their content is
worth reusing as an ad. Those two decide the rebooking.

## The rebook decision

| Signal | Action |
|---|---|
| Cost per order under target, content reusable | Rebook immediately, ask for a bundle |
| Cost per order under target, content weak | Rebook with a tighter brief |
| Views high, orders low | Wrong audience or wrong offer - change the creator or the landing page |
| Views low, orders decent | Small but right audience - scale with nano creators like them |
| Nothing at all | Do not rebook; record why in `notes/learnings.md` |

## Rights, in practice

- **Organic reuse** (reposting to your own feed): usually included, ask anyway.
- **Paid amplification** (running their post as an ad): must be bought, 25-100% of fee.
- **Website and packaging use**: buy it explicitly, with a duration.
- **Talent and likeness release**: needed if the creator appears in your own ads.
- **Keep the file.** A screenshot of the agreement and the post is the only defence a year later.

## Anti-patterns

- **A tracker in the founder's head.** Twelve creators, one missed post, no record.
- **Paying on the promise of a screenshot.** The screenshot is the payment trigger.
- **Reporting views as results.** The read-out that gets budget renewed is the one with cost per order in it.
- **Never recording the failures.** The next campaign repeats them at the same price.
