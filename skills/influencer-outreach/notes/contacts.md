# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Creators on the bench> | Repeat campaigns | | Record real reply channel, accepted rate, delivery record |
| <Creator managers / agencies> | Shortlists at speed, 15-30% commission | | Ask for their roster, not their pitch deck |
| <Top-performing micro creators> | Always-on programme | | The highest-return relationship in this file |
| <Discovery tool account owner> | Vetting at volume | | Modash / HypeAuditor / Phyllo seat |
| <Finance / CA> | GST and TDS on creator fees | | Never quote a rate from memory |
| <Legal> | Deals with exclusivity or big rights | | Route anything above a page of terms |
| <Order system owner> | Code redemption matching | | Without this, attribution is a guess |

## Rules

- Record the rate a creator actually accepted, not the rate they asked for.
- Note who delivers on the first deadline; it predicts the second campaign.
- Never store a creator's phone number, address, contract or fee in the repo.
