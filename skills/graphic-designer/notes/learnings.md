# Learnings

Durable rules, not stories. One line each, dated when it was learned. Read this at the start of every task.

- 2026-11-01 - Design for the size the asset is actually seen at. A headline that only reads at 100% zoom is not a headline. Test at 168 px for thumbnails and at 50% screen brightness for phone creatives.
- 2026-11-01 - Most "make it look better" requests are really "make it look the same as each other". Audit the last ten assets for what repeats before changing anything.
- 2026-11-01 - Get the copy final before laying out. Reflowing around late copy is the most common wasted round in the whole job.
