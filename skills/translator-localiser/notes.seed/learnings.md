# Learnings

Durable rules, not stories. One line each, dated when it was learned. Read this at the start of every task.

| Date | Learning | Why it matters |
|---|---|---|
| | | |

## How to fill this

Add a row when a rendering, a register or a reviewer comment teaches something reusable.

- **Rendering decisions** - the term, the chosen word, and the reviewer's reason.
- **Idioms that did not travel** - and the replacement that worked.
- **Length surprises** - the UI element that broke, and the allowance it actually needed.
- **Register corrections** - what the audience rejected, and what replaced it.

No customer text, no personal names, no unpublished copy. The rule, not the document.
