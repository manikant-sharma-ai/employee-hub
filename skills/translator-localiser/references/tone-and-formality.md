# Tone and formality

Formality is the first thing a native reader notices and the last thing a
translation project specifies. Decide it once, per surface, in writing.

## The three registers

| Register | Hindi | Use for |
|---|---|---|
| Respectful / neutral | `आप` | Default for commerce, support, legal, B2B, older audiences |
| Friendly / peer | `तुम` | Consumer brands with a young audience, social copy, in-app nudges - only if the English voice is already informal |
| Intimate / rustic | `तू` | Almost never in commerce. Devotional, poetic or deliberately rural contexts only |

The mistake is not choosing `तुम`; it is mixing `आप` and `तुम` in the same
product. A push notification that says `आपका ऑर्डर` and a screen that says
`तुम्हारा ऑर्डर` reads as two different companies.

## Matching the English voice

| English voice | The Indic equivalent |
|---|---|
| "We're here to help." | `हम आपकी मदद के लिए हैं।` - warm, respectful |
| "Let's get started." | `चलिए, शुरू करें।` - inclusive, still respectful |
| "Hey! You're in." | `स्वागत है!` or a friendly `आप` form - `तुम` only for a young, informal brand |
| "Please note that..." (legal) | Formal, complete sentences, no contractions, no emoji |

Do not import the English brand's playfulness if it requires `तुम` and the
audience is 45+. Do not import formality if the brand is a Gen-Z app.

## Surface rules

| Surface | Register | Length discipline |
|---|---|---|
| App UI buttons | Respectful, imperative | 2-3 words; verbs, not nouns |
| Push notification | Respectful or friendly, per brand | 60 characters visible; the benefit first |
| Error messages | Respectful, never blaming | What happened, what to do |
| Support replies | Respectful, human | Mirror the customer's register |
| Packaging | Respectful, factual | Legal text complete, marketing text short |
| Ads | Brand register, can be colloquial | Hook in the first 5 words |
| Legal terms | Formal, unambiguous | Never shorten for style |
| IVR / voice | Spoken register, short | One instruction per line |

## Politeness that is not padding

Indian languages carry politeness through grammar (`कृपया`, the `-जी` suffix,
the conditional). English padding - "we would like to kindly request that you
consider" - becomes absurd if translated literally. Say the thing politely:

- Bad: `हम कृपया अनुरोध करना चाहेंगे कि आप...` (three layers of politeness, no action)
- Good: `कृपया अपना ऑर्डर नंबर भेजें।`

## Regional variation

- **Hindi** for Delhi/UP marketing is not the Hindi of Mumbai or Bihar. If the campaign is regional, say which.
- **Marathi** in Pune is not the Marathi of Vidarbha. Use the standard written form unless told otherwise.
- **Tamil** purism varies: some audiences reject Sanskrit loans, others accept them. Follow the brand's existing Tamil.
- **Bengali** in West Bengal and in Bangladesh differ in vocabulary. Confirm the market.

## Anti-patterns

- `तुम` in a payment failure message.
- A respectful legal notice that reads like a marketing email.
- Translating "Hey there!" literally.
- Switching register because one screen "felt too formal".
- Using a devotional register for commerce.
