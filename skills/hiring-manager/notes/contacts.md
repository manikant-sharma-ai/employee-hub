# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Founder / approver> | Bands, promotion approval, headcount | | Signs the case, not the conversation |
| <Manager of the person> | Day-to-day evidence, 1:1 notes | | The person who actually sees the work |
| <HR / admin owner> | Documents, probation dates, HRMS records | | Owns the file, not the judgement |
| <finance-ops owner> | Payroll change, settlement, statutory dues | | Numbers come from here, never estimated |
| <CA> | Gratuity, notice pay, statutory entitlements | | Law and contract, not management discretion |
| <Internal committee member> | POSH and harassment process | | Statutory route; this role does not handle it |
| <Buddy, per new hire> | Week-one questions | | Brief them before day one, not on the day |
| <External recruiter, if any> | Replacement pipeline if a PIP ends in exit | | Keep warm before it is needed |

## Rules

- Record the role and the relationship, never identity documents, bank details or medical information.
- Note the person's stated ambition and constraint; that is what makes the next conversation useful.
- Never store one person's pay in this file.
