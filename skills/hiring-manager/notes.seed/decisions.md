# Decisions - hiring-manager

Schema only. A decision goes here when it was contested or when it will be
questioned later.

## Format

| Date | Person / role | Decision | Evidence relied on | What would reverse it | Review date |
|---|---|---|---|---|---|
| | | | | | |

## Decisions that always belong here

- Probation confirmed, extended or exited, with the criteria used
- Any promise made in an offer that differs from the standard terms
- A rating that was calibrated up or down, and why
- A counter-offer made to a resignation
- Any change to a scorecard after the person started
