# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Chair> | Agenda, pre-read call, contested items | | Note what they want decided, and what they will not put to a vote |
| <Directors> | Attendance, papers, declarations | | Record the question each one reliably asks - that is the page you write first |
| <Independent director> | Challenge, committee chairing, risk | | They read the risk page; make it worth reading |
| <Company secretary / CS firm> | Statutory forms, registers, filings, notice validity | | Confirms which resolutions need a filing, and by when |
| <Statutory auditor> | Management letter, accounts, audit committee papers | | Ask what they will qualify before the pack is written |
| <Lawyer> | Articles, SHA, related-party approvals, privileged advice | | This role briefs; the lawyer opines |
| <CFO or finance lead> | Management accounts, cash, runway, the numbers page | | The source of every figure in the pack |
| <Bank relationship manager> | Sanction letters, mandates, minutes they will ask for | | Banks read minutes; write them for that reader |
| <Registrar and transfer agent> | Share transfers, register of members, AGM logistics | | Only where listed or widely held |
