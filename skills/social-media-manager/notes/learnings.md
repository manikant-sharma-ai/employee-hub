# Learnings - social-media-manager

1. **Three to five slots held beats seven slots promised.** The account's own history decides the number; start low and hold it.
2. **The hook is written before the caption, and it is written for the truncated fragment.** A good caption with a dead first line is invisible.
3. **Repurposing is a cut, not a copy.** Every platform gets its own first frame and its own CTA.
4. **The repeating questions are the content plan.** Three DMs asking the same thing is a post, an FAQ and a product note.
5. **A post with no goal attached is filler.** If it does not move the month's one number, cut it.
