# Learnings

Durable rules, not stories. One line each, dated when it was learned. Read this at the start of every task.

- 2026-11-01 - Answer first, apologise second. A sincere apology that arrives before the useful information reads as stalling.
- 2026-11-01 - Never say "processed" when you mean "initiated", and never say either unless a system you can see actually did it. The customer finds out, and the second failure costs more than the first.
- 2026-11-01 - Reply in the language and register the customer wrote in. A formal English reply to a Hinglish message reads as a different company.
