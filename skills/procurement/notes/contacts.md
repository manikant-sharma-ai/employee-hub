# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Vendors - commercial contact> | Quotes, negotiation, price changes | | One row per vendor, with the rate contract reference |
| <Vendors - dispatch/service> | Delivery, breakdown, warranty claims | | The number that is answered at 9 p.m. matters most |
| <Stores / receiving> | GRN, short delivery, damage | | The person who must not be the buyer |
| <finance-ops / bookkeeper> | Payment scheduling, three-way match | | Payment terms and MSME 45-day rule |
| <legal-drafter> | Supply contract, liability, jurisdiction | | Commercial terms come from here |
| <CA / tax-prep> | GST rate, input credit, HSN | | Before a GST rate is quoted as fact |

## Rules

- Two contacts per vendor: commercial and service. The second is the one that saves a shutdown.
- Record the delivery performance next to each vendor: on time, late, short.
- Never keep vendor KYC documents outside the business's own systems.
