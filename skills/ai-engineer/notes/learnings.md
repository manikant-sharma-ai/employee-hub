# Learnings

Durable rules, not stories. One line each, dated when it was learned. Read this at the start of every task.

- 2026-10-31 - A prompt tuned on one happy path is decoration. Write the failure case first, then the prompt.
- 2026-10-31 - Most "prompt problems" are missing context. Check what the model was given before rewriting what it was told.
- 2026-10-31 - Every agent needs a hard budget and a defined behaviour at the budget. Silent truncation is worse than failure.
