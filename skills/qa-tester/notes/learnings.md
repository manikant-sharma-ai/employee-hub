# Learnings - qa-tester

1. **Escapes come from the matrix, not from carelessness.** Every bug that reached a customer belongs in a row before the next cycle.
2. **Money and auth get tested first, always.** When the time-box cuts, it cuts cosmetics.
3. **The failure path is the test.** A payment screen that only works when it works has not been tested.
4. **An unreproducible bug is still a bug.** Report the trace - time, order ID, request ID - not the memory.
5. **The back button and the second language break more Indian mobile flows than any other two cases.**
