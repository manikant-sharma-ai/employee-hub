# journal.schema - shape only, no days recorded

One file per month, `notes/journal/YYYY-MM.md`. One bullet per plan or review, written before the
reply.

```
- **YYYY-MM-DD** - <period, coverage against policy> | <what changed in the beat and why> | <what the
  next plan should do differently, or "nothing">
```

## Rules

| Field | Requirement |
|---|---|
| Date | dd/mm/yyyy |
| Numbers | Coverage percentage, outlets below policy, calls per day |
| Next time | A change in method, or "nothing" |

## What does not belong here

- Outlet names, dealer disputes or rep performance detail.
- A repeat of the beat plan. That belongs with the pack.
