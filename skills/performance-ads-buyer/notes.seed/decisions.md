# Decisions - performance-ads-buyer

Schema only. Every budget change above 20% and every kill belongs here.

## Format

| Date | Decision | Campaign | Evidence (CPA, sample, days) | Rule applied | Review date |
|---|---|---|---|---|---|
| | | | | | |

## Decisions that always belong here

- A campaign paused or killed, with the rule and the sample
- A budget change above 20%
- A new audience or a lookalike refresh
- A change to the conversion event or attribution window
- Any spend approved above the standing ceiling
