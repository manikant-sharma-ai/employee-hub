# Decisions

| Date | Question | Decision | Why |
|---|---|---|---|
| 2026-11-05 | One campaign per objective or one per audience? | Objective first, audience at ad set level | Two objectives in one campaign means neither is optimised |
| 2026-11-05 | Who executes changes in the ad account? | The account holder, on an approved change list | This role prepares and recommends; spend stays with a person |
| 2026-11-05 | Report platform ROAS or reconciled revenue? | Reconciled revenue, with the gap named | The platform's number is a claim, not a fact |
| 2026-11-05 | Test creative and copy together? | Never - one variable per test | Two variables make the result unattributable |
| 2026-11-05 | Scale by duplicating ad sets? | No - raise budget 20% or open a genuinely new audience | Duplicates compete for the same budget |
| 2026-11-05 | Quote budgets with or without GST? | Always state which; default to ex-GST with the 18% noted | Revenue and CPA both shift by 18% otherwise |
