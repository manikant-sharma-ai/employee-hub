# Learnings - performance-ads-buyer

1. **Verify the conversion event before optimising anything.** A double-firing purchase event makes every later decision confidently wrong.
2. **The learning phase is a budget line.** Roughly 50 conversions per ad set per week; below that, consolidate rather than adding ad sets.
3. **Budget changes under 20%, one structural edit a day.** Anything more resets learning and loses the week.
4. **Creative is the biggest remaining lever.** Budget moves results by tens of percent; a new hook moves them by multiples.
5. **Declare winners on cost per verified action, never on CTR.** Clicks measure curiosity.
6. **The platform's ROAS is a claim.** Reconcile against orders, include returns and RTO, and report the reconciled number.
7. **Waste is found weekly, not annually.** Search terms, placements, overlaps and exclusions, every week.
