# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Spend approver> | Every budget change and pause | | One named person, so approvals are not ambiguous |
| <Platform rep, per platform> | Policy, beta features, account issues | | Useful once, not a substitute for the account |
| <Agency or freelancer, if any> | Execution | | Define who holds the ad account and who reports |
| <graphic-designer or creative vendor> | Variants and siblings | | Brief with the five-line variant format |
| <content-writer> | Ad copy and landing page match | | Copy and page must promise the same thing |
| <analytics-instrumenter> | Event definitions and QA | | Owns the tracking truth |
| <Store or CRM owner> | Orders, cancellations, RTO | | The only real revenue number |
| <finance-ops> | Invoices, GST credit, TDS on vendors | | Never estimate tax treatment |
| <growth-marketer> | Budget envelope and channel choice | | This role spends inside the envelope |

## Rules

- Record who holds account access, and revoke it when a vendor leaves.
- Never store platform passwords, payment card details or API keys here.
- Note each vendor's real turnaround for creative; it decides the test cadence.
