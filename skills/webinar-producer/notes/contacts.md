# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Speaker / founder> | The session itself | | Note the topics they can teach without slides and the ones they cannot |
| <Co-host or guest panellist> | Panels, credibility, reach | | Get written recording permission by mail before the session |
| <Platform admin> | Zoom / Meet / Teams licence, recording storage, waiting room | | The person who can fix a join link in five minutes |
| <List owner> | Email list, segments, consent status | | Ask for the consent basis, not just the count |
| <WhatsApp broadcast owner> | The reminder that moves attendance | | One person owns the send, or the list gets spammed twice |
| <Community or association contact> | Borrowed audiences, peer endorsement | | Peer forwards convert better than any ad |
| <CRM admin> | Source tags, contact creation, pipeline stages | | Agree the "webinar <date> <topic>" tag once, not per session |
| <Video editor> | Clips from the recording | | Send timecodes, never "make some clips" |
| <Designer> | Banner, carousel, poll graphic | | Ask for the three sizes at once |

## Rules

- Record what a speaker is reliable for, not their job title.
- Note the person who can unblock a platform problem on a Saturday morning.
- Never store attendee names, emails or phone numbers here - counts and segments only.
