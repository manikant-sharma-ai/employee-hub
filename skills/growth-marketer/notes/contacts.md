# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Founder> | Budget envelope, risk appetite, payback tolerance | | Sets the maximum CAC the business can fund |
| <performance-ads-buyer or agency> | Campaign execution and pacing | | Recommends allocation; they build and pace |
| <seo-specialist> | Search demand and page shape | | Organic loop owner |
| <content-writer> | The words that carry the promise | | Message tests need copy fast |
| <analytics-instrumenter> | Events and funnel definitions | | Without this, no rate is trustworthy |
| <Sales head or founder> | Why customers actually buy | | The highest-value conversation in this file |
| <Creator or influencer, per category> | Borrowed reach | | Rate, audience fit, past performance |
| <Marketplace account manager> | Demand and fees on Amazon, Flipkart, IndiaMART | | Fee changes move the mix |
| <Payment gateway or finance> | COD share, RTO rate, settlement cycle | | RTO is a channel cost, not a footnote |

## Rules

- Record which channels have already been tried and what the outcome was; that is the most useful column.
- Never store creator contracts or personal contact data beyond what the job needs.
- Never record a spend figure without its date.
