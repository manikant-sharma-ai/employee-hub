# Decisions - growth-marketer

Schema only. Every channel started, paused or scaled belongs here with its payback.

## Format

| Date | Decision | Evidence (CAC, payback, sample) | Owner | Review date |
|---|---|---|---|---|
| | | | | |

## Decisions that always belong here

- A channel started or stopped, with the CAC that justified it
- An experiment declared a win, with the sample and the duration
- An experiment abandoned early, and why
- A spend ceiling set or raised
- A metric definition changed, and from which date it applies
