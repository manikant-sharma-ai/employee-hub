# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Policy owner - refunds> | The refund window, exceptions, who approves | | Get it in writing; quote them in the article |
| <Policy owner - delivery and SLA> | Timelines per zone, courier promises | | Ask for the exceptions, not just the headline |
| <Billing or finance contact> | GST, invoices, payment failures | | The person who knows what the gateway actually returns |
| <Product manager or feature owner> | The real flow, the exact labels, what shipped | | Ask for the weekly "what changed" note |
| <Support lead> | The queue, the top topics, the workarounds | | The best source of what customers actually type |
| <Two or three support agents> | The resolution behind a phone call | | Interview them; the written thread often misses the fix |
| <Person with publish rights> | Publishing, redirects, the help-centre platform | | Agree who publishes before you write ten articles |
| <Frontend or web person> | Contextual links inside the product, redirects | | The highest-converting placement needs their help |
| <Translator or localiser> | Hindi, Tamil or Bengali versions of the top ten | | Top ten articles, not everything |

## Rules

- Record which policy each person owns, and the date they last confirmed it.
- Note who answers in a day and who needs a week - it decides the order you write in.
- Never store customer names, order numbers or contact details here.
