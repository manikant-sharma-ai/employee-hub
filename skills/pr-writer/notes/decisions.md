# Decisions

| Date | Question | Decision | Why |
|---|---|---|---|
| 2026-11-04 | One angle for every outlet, or one per outlet? | One per outlet, three variants maximum | A business daily and a regional paper want different facts from the same announcement |
| 2026-11-04 | Send the release as an attachment? | Paste in the body, link the press kit | Attachments get filtered and unread |
| 2026-11-04 | Do we offer an exclusive? | One outlet, one fact, one 24-hour window | Five "exclusives" is a reputation problem |
| 2026-11-04 | Do we report AVE? | No - reply rate, coverage rate, message pull-through, referral signups | AVE is a made-up multiplier no buyer uses |
