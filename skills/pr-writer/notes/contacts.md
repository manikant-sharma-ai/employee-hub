# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Founder / spokesperson> | Quotes, approvals, interviews | | Approves the exact words, in writing |
| <Second spokesperson> | The technical or financial questions | | Named in the Q&A sheet per question |
| <Journalists, one row each> | Coverage by beat | | Beat, last three pieces, reply history |
| <Press-kit owner> | Logos, photos, product shots | | Keeps the Drive folder current |
| <Legal-drafter / lawyer> | Anything with a case, a regulator or a claim | | Before any quote is issued |
| <Investor relations contact> | Funding stories that need an investor quote | | Investor quote needs their own approval |

## Rules

- One row per journalist, updated the same day they reply. The list is the asset.
- Never store a personal phone number a reporter did not give you.
- Record what a journalist never covers, not only what they do.
