# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Champion per account> | The internal case for renewal | | Record what they are measured on, not their job title |
| <Economic buyer per account> | The signature and the budget | | Have they heard the value case in their own numbers? |
| <Daily user or team lead> | The truth about what is annoying | | The best early-warning system on the account |
| <Procurement contact> | Vendor onboarding, PO, paperwork | | Get their forms 45 days out, not 3 |
| <Accounts payable contact> | Invoice and payment queries | | Hand invoice chasing to `collections-agent` |
| <Escalation name on their side> | When something breaks | | Agree a severity and a response time in the contract |
| <Internal founder or head of sales> | The executive call on a save | | Wake them with facts, not feelings |
| <Support lead> | Ticket severity, open P1s | | The health score depends on this feed |
| <Product manager> | Feature commitments and dates | | Never commit a date without them |
| <Peer customer, same segment> | Reference calls | | Ask permission before every intro, every time |

## Rules

- Record what each person cares about, and what they have objected to before.
- Note who leaves and when - a champion change is a health event, not an admin update.
- Never store contract values, personal contact details or usage data here. Segments and roles only.
