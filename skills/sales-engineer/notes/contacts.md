# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Buyer's technical owner> | Environment facts, data extract, POC execution | | The POC stands or falls on this person's availability |
| <IT gatekeeper / security reviewer> | Questionnaire, residency, access model, DPA | | Involve in week one, not week three |
| <Economic buyer> | The decision, the deadline, the budget | | Confirm the decision date in writing |
| <Champion> | Internal selling, the retell | | Give them the three sentences after every call |
| <Integration or implementation partner> | Their ERP or middleware surface | | Ask them the API question, not the buyer |
| <Internal product owner> | What the product does today, roadmap status | | The only acceptable source for a capability claim |
| <Implementation lead> | Whether the scoped effort can actually be delivered | | Ask before promising a date |
| <Legal / DPO on the client side> | DPA, data deletion, sub-processors | | Never agree terms; route to `legal-drafter` |
| <Reference customer, similar profile> | A peer who will take the call | | Ask permission before every reference |
