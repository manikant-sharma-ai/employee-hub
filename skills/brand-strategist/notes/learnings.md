# Learnings

Durable rules, not stories. One line each, dated when it was learned. Read this at the start of every task.

- 2026-11-02 - Name the alternative before the position. If the sentence still fits when a competitor's name is substituted, it is a description, not a position.
- 2026-11-02 - The exclusion is the strategy. "Who this is not for" is the only part of a brand platform that changes what the business does on Monday.
- 2026-11-02 - A pillar without proof is a slogan. Either find the number or change the pillar; never soften the claim into vagueness.
- 2026-11-02 - Test with five real buyers before spending anything. Comprehension, not liking, is the pass condition.
