# Positioning

Positioning is not a tagline. It is the choice of which buyer you serve, what you are an alternative to, and why you are the better choice for that buyer in that situation.

## The internal statement

```
For  [buyer in a specific situation]
who  [has this problem and currently solves it with X]
we are the [category frame]
that [difference that matters to them]
because [proof: mechanism, customer, number]
```

Every blank is a decision. If a competitor's name fits the same blanks, the position is not yet a position.

## Worked example - inventory software for auto-parts makers

| Element | Weak version | Strong version |
|---|---|---|
| Buyer | "SMEs in India" | "Tier-2 auto-parts makers with 2-5 godowns and an OEM audit each year" |
| Alternative | "manual processes" | "Tally plus a WhatsApp group plus one person who remembers" |
| Frame | "supply chain platform" | "stock-count and audit-trail system for OEM suppliers" |
| Difference | "easy to use" | "counts by barcode in a shift, and produces the audit trail the OEM asks for" |
| Proof | "great support" | "a Pune tier-1 supplier cut reconciliation from 11 days to 2" |

The weak column could describe 400 companies. The strong column describes about 30 in Maharashtra and can be sold by a person who has never met the buyer.

## The three positioning moves

| Move | When | Risk |
|---|---|---|
| Take a position inside an existing category | The category is known and the buyer already budgets for it | You compete on the category's terms, including price |
| Sub-segment the category | You are strongest for one slice | You must be visibly better for that slice, not just narrower |
| Create or rename a category | The existing category actively misleads the buyer | Expensive; you teach the market before you can sell to it |

Default to sub-segmenting. It is the cheapest move that produces a real difference, and it is reversible.

## Choosing the buyer, which is where the money is

| Question | Why it decides the position |
|---|---|
| Which segment has the highest retention? | The position should attract the people who stay |
| Which segment pays the most for the same work? | Where the margin is, the message goes |
| Which segment has the shortest sales cycle? | Speed funds the next stage |
| Which segment refers others? | Referral segments compound |
| Which segment do we lose to competitors? | Either the position is wrong for them or the product is |

Then write the exclusions: "not for single-godown traders, not for companies already on SAP, not for government buyers." An exclusion is not a rejection of revenue; it is a decision about which revenue is repeatable.

## The category choice

| Situation | Frame to use |
|---|---|
| Buyer already has a budget line | Use the budget line's name - it is the word they search |
| Buyer has no budget line and no vocabulary | Use the closest familiar thing and add the difference: "a stock register that updates itself" |
| Category is tainted (failed implementations, bad vendors) | Name the taint and position as the opposite, with evidence |
| Two categories both fit | Pick the one with the shorter sales cycle |

## Testing a position in an hour

1. Write the statement.
2. Write the same statement for three competitors, honestly. If yours is interchangeable, rewrite.
3. Read the one-liner to five people who match the buyer definition, and ask: "what do you think we do, and who is it for?"
4. Count how many repeat it back correctly. Below three of five, it is not finished.
5. Ask: "what would you expect this to cost?" The number reveals the frame the buyer actually heard.

## Anti-patterns

- **Positioning by adjective.** "Innovative", "seamless", "world-class" are claims about the sender, and every competitor uses them.
- **Positioning to the total addressable market.** It reads as a company that has not decided, and it sells to nobody.
- **A position that requires the buyer to change vocabulary before they can buy.** Teaching is expensive; borrow their words.
- **Copying the market leader's position with "cheaper" attached.** It makes price the only axis, which is the one you least want.
- **Positioning on a feature a competitor can ship in a quarter.** Positions built on a mechanism survive; positions built on a feature do not.
- **Never revisiting the position.** A position is a decision with a review date, not a monument.
