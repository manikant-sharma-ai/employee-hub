# Category and competitor framing

The buyer puts you in a box before they compare you to anything. Deciding which box is a strategic act; leaving it to the buyer means competing on the terms of whoever got there first.

## The competitor set, defined properly

| Type | Example | Why it matters |
|---|---|---|
| Direct | Another inventory system for the same buyer | The obvious comparison; rarely the real one |
| Indirect | Tally plus a WhatsApp group plus one reliable person | Usually the actual incumbent |
| Status quo | "We manage" | The most common competitor, and the hardest to beat |
| Budget competitor | The OEM audit penalty, or the consultant | The money may be going here |
| Do-nothing | Nobody has decided | Free, and winning by default |

Rule: **the status quo is the competitor to beat**, because most deals are lost to it, not to a rival.

## Reading a competitor's positioning

| What to look at | What it reveals |
|---|---|
| Homepage headline | The claim they want to own |
| The first three bullets | What they think the buyer's priority is |
| Pricing page, or its absence | Whether they sell on price or on a demo |
| Case studies | Which segment actually pays them |
| Job posts | Where they are investing next; the most honest signal available |
| Review sites | The complaints, in the buyer's words |
| Their changelog | Whether they are closing the gap you are positioning on |

## Framing moves

| Move | When to use | The sentence it produces |
|---|---|---|
| Reframe the problem | The category solves a different problem than the buyer's real one | "This is not an inventory problem, it is an audit problem" |
| Narrow the category | You are best for one slice | "The stock system for OEM suppliers, not for retail" |
| Raise the stakes | The buyer underestimates the cost | "Every untracked transfer is a discount you gave away" |
| Lower the stakes | The buyer thinks it is a big project | "Two godowns, one shift, two weeks" |
| Change the comparison | You lose on the incumbent's axis | Compare to the audit penalty, not to the other software |
| Own the constraint | The market has a common objection | "Built for Tally, because you are not replacing Tally" |

## The competitive matrix that is honest

| | Us | Competitor A | Competitor B | Status quo |
|---|---|---|---|---|
| Buyer served | | | | |
| Core mechanism | | | | |
| Where we are worse | | | | |
| Proof we have | | | | |
| Price frame | | | | |

Filling in "where we are worse" is what makes the rest credible. A matrix where you win every row is a brochure, and buyers read it as one.

## What to say about competitors

| Do | Do not |
|---|---|
| Compare on a mechanism, factually | Name them in public copy without a legal review |
| Acknowledge what they are good at | Claim they are "unsafe" or "a scam" without evidence |
| Say who you are not for | Say they are for nobody |
| Use the buyer's words about the trade-off | Use internal competitive language that leaks into customer calls |

## Category creation, priced honestly

| Cost | Detail |
|---|---|
| Teaching | Every message must explain the category before the product |
| Sales cycle | Longer; the buyer has no budget line to charge it to |
| Content | You write the definitions others will eventually borrow |
| Analyst and review coverage | None exists; you build your own proof |
| Risk | A larger player can adopt the term and outspend you on it |

Create a category only when the existing one actively misleads the buyer into a comparison you lose. Otherwise sub-segment inside the existing category - it is cheaper, faster and reversible.

## Anti-patterns

- **Positioning against the wrong competitor.** Beating a rival you rarely meet, while losing to the spreadsheet.
- **A category name nobody searches.** You cannot be found by a word the buyer has never typed.
- **Claiming a category you do not lead.** If a bigger player defines it, you are a follower with extra vocabulary.
- **Competitor-obsessed messaging.** It makes the buyer think about them, not about you.
- **A matrix that omits your weaknesses.** The buyer finds them in the demo, and everything else becomes suspect.
- **Reframing the problem without evidence.** A reframe is a claim about the buyer's world; it needs their words, not yours.
