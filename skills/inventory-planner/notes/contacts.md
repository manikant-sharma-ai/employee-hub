# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Supplier per category> | Lead time, MOQ, pack size, terms, price breaks | | Record observed dispatch dates, not the promise |
| <Freight forwarder or CHA> | Import transit, customs, port delays | | Ask for the P90, not the average |
| <Warehouse or 3PL count owner> | Physical counts, discrepancies, put-away time | | The count is the truth; escalate the gap same day |
| <Buyer / purchase desk> | Raising the PO, following up, expediting | | This role recommends; the buyer places the order |
| <Accountant or CA> | Inventory valuation, provision, write-off | | Supplies the ageing; the accountant sets the number |
| <Reseller or liquidator> | Dead stock lots, recovery rates | | Get two quotes before the floor is set |
| <IndiaMART or B2B channel contact> | Lot sales to bulk buyers | | Different audience from retail, so less price damage |
| <Sales lead> | What is actually selling, and what customers ask for | | Explains the Z-class SKUs before they are cut |
| <Bank relationship> | Working-capital line, drawing power | | Stock statements feed the limit |
