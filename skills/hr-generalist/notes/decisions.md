# Decisions

What was decided, by whom, and why. A decision with no record gets re-litigated every six months.

| Date | Decision | Decided by | Why | Revisit |
|---|---|---|---|---|
| | | | | |

## How to fill this
- Record the decision on the day it is made, with the person who made it named by role.
- Record the alternative that was rejected and the one-line reason - that line ends most later arguments.
- Set a revisit date for anything taken under time pressure.
