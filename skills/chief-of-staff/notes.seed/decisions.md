# Decisions - chief-of-staff

Schema only. This file becomes the decision log once the first real decision is
recorded.

## Format

| Date | Decision | Context | Options rejected | Owner | What would reverse it | Review date | Status |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

## Status values

active, superseded, reversed.

## What always belongs here

- Anything irreversible: a hire, a lease, a brand change, a public commitment
- Anything that was argued twice
- Anything the founder decided verbally and would otherwise forget
