# The weekly operating review

One page, 45 minutes, two or three decisions. Everything else is a status meeting
with a different name.

## The one page

Five rows at most. Each has a number, a target, the trend against last week, and a
colour. If a row cannot be filled with a source, it does not belong on the page.

| # | Metric | This week | Target | Trend | Colour |
|---|---|---|---|---|---|
| 1 | Revenue booked | | | up / flat / down | |
| 2 | Gross margin % | | | | |
| 3 | Cash in bank, and weeks of runway | | | | |
| 4 | Pipeline or order book | | | | |
| 5 | The one that matters this quarter | | | | |

The fifth row changes each quarter. It is the number that would tell you the
quarter is going to be missed before the revenue line does - a delivery backlog, a
churn count, a hiring gap, a support queue age.

## What makes a number usable

- **A source.** The sheet, the books, the CRM, the gateway. Named.
- **A period.** This week, last week, month to date. Not "currently".
- **A definition.** Revenue booked or collected are different numbers; both are
  legitimate; mixing them across weeks is how a review loses trust.
- **A comparison.** Against target and against last week. A number alone is trivia.

## The 45 minutes

| Minutes | Item | Output |
|---|---|---|
| 0-5 | The page, read in silence | Nobody presents; everyone has read it |
| 5-15 | What changed, and why | One line per red or amber row |
| 15-25 | What is stuck | The blocker, the owner, the decision needed |
| 25-40 | The two or three decisions | Decision, owner, date, reversal test |
| 40-45 | Last week's commitments | Closed, slipped, dropped - named |

Read in silence is the single highest-leverage rule. It removes the twenty minutes
usually spent narrating a slide.

## The three questions

Ask the same three every week, in this order:

1. **What changed since last week that we did not expect?** Finds the new fact.
2. **What is stuck, and what decision unblocks it?** Finds the real agenda.
3. **What are we saying no to this week?** Forces the trade-off that a busy week
   otherwise avoids.

A review that answers only the first two becomes a reporting ritual. The third is
what makes it operating.

## Colour rules, written down

| Colour | Test | Required in the meeting |
|---|---|---|
| Green | At or above target, or within the agreed band | Nothing |
| Amber | Within 10% of target and trending down, or a known risk with a date | The cause and the fix date |
| Red | Below target, or a risk with no owner | A decision this week |

Two consecutive reds on the same row is not a metric problem. It is a decision the
founder has not taken, and the review names it that way.

## Attendees

- Three to six people. Every additional attendee adds ten minutes and removes a
  decision.
- One owner per number on the page. They bring the figure and the cause.
- Anyone who is only listening is not invited. Send them the page.

## Anti-patterns

- **The presentation.** A deck in a weekly review means someone is managing upward
  instead of operating.
- **The status round-robin.** "I did this, then I did that" produces no decision.
- **The new metric every week.** A page that changes shape cannot show a trend.
- **The 90-minute review.** Length is a symptom: the page has too many rows or the
  decisions are being avoided.
- **The review that never says no.** If nothing was declined, the week was
  allocated by whoever asked loudest.
- **No note.** A review with no written output is a conversation that will be
  repeated next Monday.
