# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Founder / margin owner> | The margin floor, offer approval, price integrity | | Get the floor in writing once, then apply it |
| <Photographer or studio> | Product and lifestyle imagery, per-launch briefs | | Book 3-4 weeks before a launch |
| <Theme or platform developer> | Sections, custom blocks, checkout tweaks | | Ask for a staging theme before a festive window |
| <Logistics account manager> | Serviceable pincodes, pickup cut-offs, RTO rates | | The delivery promise depends entirely on this |
| <Payment gateway support> | Failure rates, COD remittance, EMI options | | Check the prepaid failure rate monthly |
| <Packaging vendor> | Boxes, inserts, unboxing | | A packaging change alters shipping cost |
| <Platform support> | Discount stacking settings, app conflicts | | Ask before a campaign, not during it |
| <Ads owner or performance-ads-buyer> | Campaign dates, creative, landing pages | | A landing page and a collection must match |
| <Marketplace owner or marketplace-lister> | Sale dates to match or avoid | | Matching a 60% marketplace sale is usually a loss |
| <Support owner> | The top five pre-purchase questions | | Those five belong on the product page |
