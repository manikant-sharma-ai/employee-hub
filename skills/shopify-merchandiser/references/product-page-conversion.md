# Product page conversion

The product page is the only page where a visitor decides. Everything else in the store exists to
get them here.

## The above-the-fold block, on a phone, in this order

| # | Element | Rule |
|---|---|---|
| 1 | Image | The product, filling the width, first frame shows the whole product |
| 2 | Title | What it is, in the words a customer searches |
| 3 | Price | Actual price, MRP struck through, discount % - the same way everywhere |
| 4 | Rating and review count | Only if real; a fake count is a legal and trust risk |
| 5 | One-line differentiator | The single reason to buy this one over the next |
| 6 | Variant selector | Size or colour, with unavailable ones visible and disabled |
| 7 | Offer line | Prepaid discount, bundle, free shipping threshold - one offer, not four |
| 8 | Delivery promise | "Delivered by Fri, 15 Nov to 560001" - the highest-leverage element |
| 9 | Add to cart | Full width, sticky on scroll, and above the fold on a 390px screen |
| 10 | Trust line | COD available, 7-day returns, secure payment - one line, three claims |

If any of 3, 8 or 9 is below the fold on a phone, the page is broken regardless of how good the
rest is.

## Below the fold, in the order objections arrive

| Block | The objection it answers |
|---|---|
| Three to five benefit bullets | "What does it actually do for me" |
| Images in context | "What does it look like in real life" |
| Size or spec table | "Will it fit / work" |
| What is in the box | "What do I get for this price" |
| Care or usage | "Will it last" |
| Shipping, returns, COD | "What if I do not like it" |
| Reviews with photos | "Do people like it" |
| FAQ, five questions | "The thing I would have emailed about" |
| Complete the set | "What else do I need" |

## The delivery promise is worth more than a discount

| Element | Effect | How to get it |
|---|---|---|
| Pincode-based date | Removes the biggest unknown in Indian D2C | Logistics connector with serviceability by pincode |
| Cut-off time | "Order in 4h 20m for delivery by Friday" | Courier pickup time |
| COD availability by pincode | Prevents a checkout dead end | Gateway and courier rules |
| Return window stated plainly | Reduces hesitation and support load | Policy, in one line |
| Free shipping threshold shown as progress | Raises AOV | "₹240 away from free delivery" |

Never show a date the courier cannot hold. A missed promise costs the order, the return and the
review.

## Conversion elements, ranked by evidence in a small store

1. **Real product photography** in context, not on white only.
2. **A visible delivery date** by pincode.
3. **Reviews with photos** - even twelve is enough to move a page.
4. **A price that looks decided** - not three struck-through numbers.
5. **A single clear offer**, not a stack of four badges.
6. **A size or spec guide** that answers the question people email about.
7. **Sticky add-to-cart** on mobile.
8. **A short, scannable description** - five bullets beat five paragraphs.
9. **Payment options shown early** - UPI, cards, COD, EMI where relevant.
10. **A visible return policy** within one tap.

## Copy that sells without inventing claims

| Instead of | Write |
|---|---|
| "Premium quality fabric" | "210 GSM combed cotton - heavy enough to hold shape after 40 washes" |
| "Best seller" | "Bought 1,400 times since April" (only if true) |
| "Loved by customers" | "4.6 from 218 reviews" |
| "Fast delivery" | "Delivered in 3-5 days to 18,000+ pincodes" |
| "Easy returns" | "7-day return, pickup from your address" |

Every claim must be checkable. A material claim the operations team cannot substantiate is a
consumer-protection exposure, not a copy decision.

## The mobile checklist, run before publishing

| Check | Pass condition |
|---|---|
| Above the fold | Image, price, delivery, ATC visible without scrolling on 390x844 |
| Tap targets | Every button at least 44px, no overlapping |
| Image weight | Under 200KB per image, lazy-loaded below the fold |
| Variant change | Price, image and stock update without a reload |
| Add to cart | One tap, with a visible confirmation and a cart drawer |
| Forms | Pincode check needs no keyboard switch |
| Speed | Page interactive under 3 seconds on 4G |
| Zoom | Product images zoomable, because detail sells |

## Anti-patterns

| Anti-pattern | Cost |
|---|---|
| A carousel as the first image | Half the visitors never see the second image |
| Price only after the variant is picked | The visitor does not know the price at a glance |
| Five offer badges | The page reads as a discount shop |
| Description copied from the supplier | No differentiation, and sometimes a false claim |
| Reviews imported from another store | A trust and legal risk |
| Delivery date promised without courier data | Returns, chargebacks and reviews |
| Sticky ATC that covers the variant selector | The button blocks the thing it needs |
| No size guide | The single most common support ticket in apparel |
