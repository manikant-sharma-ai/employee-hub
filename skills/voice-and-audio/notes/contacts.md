# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Host / founder> | Editorial decisions, final cut approval | | Prefers a cut list to a re-listen |
| <Editor / audio engineer> | Executes the chain and the cut | | Ask what DAW they use before writing settings |
| <Guests> | Episodes | | Record time zone and mic setup after the first session |
| <Studio with a treated room> | When the home room fails | | Hourly rate worth keeping on file |
| <Transcriber / Descript account owner> | Timecoded transcripts | | Without timecodes, cuts are approximate |
| <Podcast host admin> | Chapters, RSS, publish | | The only person who can push the episode live |
| <Music licensing contact> | Beds and stings | | Rights are cleared by a person, never assumed |

## Rules

- Record a guest's preference once: in-room, remote, or a voice note only.
- Never store a guest's phone number, address or contract terms here.
- Note who delivers on the first deadline; the second episode is where it shows.
