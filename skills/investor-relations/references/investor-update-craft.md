# Investor update craft

An investor update is a one-page letter with numbers in it. Its job is to keep the
people who backed you informed enough to help, and confident enough not to worry.

## The five sections, in this order

| Section | Length | Job |
|---|---|---|
| 1. What changed | 3-5 sentences | The month in plain language, good and bad |
| 2. The numbers | A table | Revenue, growth, cash, burn, runway, customers, the round's metric |
| 3. Where we are short | 2-4 sentences | The miss, stated first, with the cause |
| 4. What we are doing | 3-5 bullets | The plan, with dates and owners |
| 5. The ask | 1-2 sentences | One specific request |

Same order every month. A reader who has four minutes finds the bad news in
section three without reading the rest, and a reader who has thirty seconds reads
the table.

## Section 1 - what changed

Write it as a sentence a colleague would say, not a press release:

> "We closed two enterprise pilots and lost the biggest one we expected to convert.
> Hiring slipped by a month because the offer was declined. Revenue grew 6% against
> a plan of 11%."

Not:

> "We are pleased to report continued momentum across several strategic
> initiatives, with encouraging progress in our enterprise pipeline."

The second version is unreadable and, worse, it is not information.

## Section 2 - the numbers table

| Metric | This month | Last month | MoM | Plan | Variance |
|---|---|---|---|---|---|
| Revenue (₹ lakh) | | | | | |
| Gross margin % | | | | | |
| Cash in bank (₹ lakh) | | | | | |
| Net burn (₹ lakh/month) | | | | | |
| Runway (months) | | | | | |
| Active customers | | | | | |
| Net revenue retention % | | | | | |
| The metric the round was raised on | | | | | |

Six to eight rows. Every figure from the workbook, cash from the bank statement.
Runway = cash ÷ trailing three-month average net burn, and say which burn you used.

## Section 3 - where we are short

The section that decides whether investors trust the rest. Four rules:

1. **State the miss before the explanation.** "We missed revenue by 12%."
2. **Give the cause, not the context.** "Two renewals slipped to January" beats
   "the market has been challenging".
3. **Say what it means for the plan.** "This pushes breakeven by one quarter."
4. **Never blame a person by name** in writing to investors.

## Section 4 - what we are doing

Three to five bullets, each with a date and an owner:

- "Renewal play for the two slipped accounts - founder, by 15 December."
- "Hiring a second AE; two candidates at final stage - 30 November."
- "Pricing test on the mid tier from 1 December, read-out in February."

Bullets without dates are intentions, and investors have read a lot of those.

## Section 5 - the ask

One ask, specific, and answerable in one email:

| Weak | Strong |
|---|---|
| "Let us know if you can help." | "An intro to a logistics CFO for a pilot - one intro, not a list." |
| "We are hiring." | "A senior backend engineer with payments experience; referral bonus ₹50,000." |
| "Any advice on growth?" | "Who ran a successful channel-partner programme at our stage? A 20-minute call." |

## Length and cadence

- **One page, under 500 words**, plus the table. Investors read on a phone.
- **Monthly**, on the same day. Quarterly only for the smallest cheque-holders, and say so.
- **The archive is public to your investors.** Each update is read alongside the previous eleven.

## Writing rules

- **Numbers before adjectives.** "Revenue ₹42.6 lakh, up 6%" beats "strong growth".
- **No jargon** - "ARR", "NDR", "CAC payback" are fine if the definition is in the data room and consistent.
- **No emoji, no exclamation marks, no "humbled".**
- **Say "I" and "we" honestly.** A founder update written in the passive voice reads as a cover-up.
- **Date it, and number it** - "Update 14, November 2026".

## Anti-patterns

- **The all-good update.** After two of them, investors discount everything.
- **A chart with no axis labels.** It looks like a pitch deck, not a report.
- **Different numbers to different investors.** The fastest way to lose a lead.
- **A late update explained by busyness.** The update is the relationship.
- **Burying the miss in section four.** It will be found, and then the format is the problem.
- **A 1,500-word essay.** Nobody reads it, and the numbers get lost.
