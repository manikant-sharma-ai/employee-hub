# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Lead investor partner> | The relationship, bad news first, pro-rata | | Record what they doubt, not just what they fund |
| <Fund analyst or platform contact> | Diligence requests, portfolio help, hiring intros | | They decide what reaches the partner |
| <Angels> | Follow-ons, intros, customer leads | | Note what each one is useful for |
| <Board observer> | Information rights, meeting cadence | | Confirm what they are entitled to before sharing more |
| <Company secretary> | Register of members, filings, resolutions | | The cap table of record lives here |
| <CA> | Statutory filings, FEMA, angel tax, ESOP tax | | Ask before any share transfer or new instrument |
| <Lawyer> | SHA rights, consents, disclosures, notices | | This role briefs; the lawyer opines |
| <Banker or payment contact> | Balance confirmations for diligence | | The document a fund will ask for twice |
| <Founders who raised recently> | Real process length, reserve behaviour | | The highest-value informal source |
| <Portfolio companies of your lead> | Customer intros, hiring, peer benchmarks | | Ask the lead first, then the company |

## Rules

- Record the last contact date per investor. A relationship with no date is one going cold.
- Note what each investor has actually offered and delivered, so the next ask goes to the right person.
- Never store an investor's terms, a cap table, a bank balance or a customer name here.
