# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Top five partners> | Revenue concentration, quarterly reviews | | Named contact each; know their payout terms |
| <Content partners in the niche> | Durable search traffic | | Slow to start, best long-run incrementality |
| <Approved coupon and cashback sites> | Volume, lower rate | | Admitted deliberately, full-price only |
| <Affiliate platform account owner> | Tracking, payouts, settings | | Whoever can change the cookie window |
| <Finance / CA> | GST, TDS, payout reconciliation | | Never quote a rate from memory |
| <Legal> | Terms, clawback enforceability | | The terms page is a contract |
| <Order system owner> | New vs returning flags, returns | | The incrementality estimate depends on it |

## Rules

- Record partner type, agreed rate and payout terms; never bank details, PAN or GSTIN.
- Note which partners were admitted deliberately and why; the next person inherits the decision.
- Track who replies and who goes quiet; dormant partners are a list, not a failure.
