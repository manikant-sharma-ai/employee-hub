# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Helpdesk admin> | Ticket exports, tag hygiene, CSAT data | The admin console | Ask for the raw text, not the reason codes |
| <Support team lead> | The patterns agents know and never record | A 20-minute conversation | Treat as hypotheses, then verify in the corpus |
| <Product manager> | Routing the build and fix dispositions | The read, with counts attached | One theme per ticket, never a deck |
| <Knowledge base writer> | Turning a repeated question into an article | The theme with the top ten tickets | The count is the brief |
| <Merchandiser / listing owner> | Fixing the expectation the listing set | The theme with the SKU list | The cheapest fix in most businesses |
| <Pricing analyst> | Themes about value and price | The segment split, weighted by value | Never send a pricing theme unsegmented |
| <Customer success lead> | Accounts behind a churn-coded theme | The account list, by theme | Handles the relationship; this role counts |
| <Sales lead> | Objections from calls that never became tickets | The call notes export | The clearest statement of what is wrong with the product |
| <Data analyst> | The volume and trend numbers behind the read | The dashboard, if one exists | Numbers are theirs, themes are this role's |
| <Community / social manager> | Comment and DM exports | The tool's export | Loud, small, and worth a separate line in the corpus table |
