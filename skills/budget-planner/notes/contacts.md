# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Founder / plan approver> | Approving the plan, the contingency rule, reforecasts | | Record the version and date approved |
| <Banker, working-capital relationship> | Overdraft limit, enhancement, the projection format they want | | Banks have their own template - ask for it first |
| <CA> | GST timing, advance tax instalments, depreciation treatment | | Model tax as an input, never as a decision |
| <Auditor> | Year-end view, provisions, one-off treatment | | Ask before the plan locks, not after |
| <Payroll / HR lead> | Headcount, CTC bands, joining months, statutory rates | | Verify PF/ESI ceilings each year |
| <Top vendor with an escalation clause> | Rate card, fuel surcharge, renewal dates | | One alternate quote a year keeps the rate honest |
| <Landlord> | Rent escalation, lock-in, quarterly payment terms | | The escalation date belongs in the assumptions register |
| <Lender for term loan / machinery> | EMI, moratorium end, floating-rate reset | | Reset dates are the most-missed cash line |
| <Chartered engineer / valuer, where a project is bank-financed> | Project cost certification | | Needed for a term loan or a subsidy claim |
