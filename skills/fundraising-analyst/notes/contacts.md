# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Lead investor partner> | The round, the process | | Record the stage, cheque size and what they doubt |
| <Angels and operator networks> | Bridge and small cheques | | Fastest path to a first yes |
| <Fund analysts> | Diligence requests | | They decide what reaches the partner |
| <CA / chartered accountant> | FEMA pricing, angel tax, ESOP tax, statutory dues | | Ask before the term sheet, not after |
| <Company secretary> | Filings, cap-table of record, board resolutions | | The cap table that diligence trusts |
| <Merchant banker or registered valuer> | Valuation report for foreign investment | | Required in practice for FEMA pricing |
| <Lawyer / legal-drafter> | SHA, SSA, term-sheet drafting | | Summarise, never opine |
| <Founders who raised recently> | Warm intros, real process length | | The highest-conversion intro source |

## Rules

- Record the stage a fund actually leads at, not the stage it says it covers.
- Note the question each investor asked twice; it is the thesis they are testing.
- Never store an investor's terms, a cap table, a bank balance or a founder's personal holding here.
