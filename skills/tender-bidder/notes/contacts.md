# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <GeM seller helpdesk> | Catalogue, category enablement, bid issues, ratings | Portal ticket | Keep the ticket number; phone rarely resolves |
| <State e-procurement helpdesk> | Registration, DSC mapping, upload failures | Portal and phone | Ask about the last-day rush before it happens |
| <DSC vendor> | Class 3 tokens, renewal, portal registration | Vendor support | Renew 60 days before expiry |
| <Bank BG desk> | EMD, PBG, performance guarantee, margin money | Written request with the order copy | Processing takes longer than the bid window |
| <CA> | Turnover and net worth certificates, Udyam-linked declarations | A specific format request | Ask for the tender's format, not a generic one |
| <OEM or principal> | Authorisation letters for specific tenders | Email with the tender reference | Keep a template agreed in advance |
| <Transport and installation partner> | Delivery to the buyer's location, site work | Rate card by city | Installation cost is where bids leak |
| <Inspection agency / buyer's QA> | Inspection schedule, sampling, test certificates | Through the buyer | Clear it before dispatch, not after |
| <Legal / contract counsel> | Order terms, deviations, a disputed LD | Before signing | The order is the contract |
| <Past buyers - repeat> | Repeat orders, completion certificates, references | A call at acceptance | The cheapest customer in the business |
