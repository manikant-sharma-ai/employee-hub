# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <Trademark agent> | Filings, examination replies, hearings | Email, with the mark and the class | Ask for the response draft before it is filed |
| <IP advocate> | Infringement and passing-off opinions, notices, suits | A short brief with the evidence pack | Never ask for an opinion without the register extract |
| <Patent agent> | Provisional and complete drafting, PCT | The invention disclosure form | Drafting quality decides the claim, and the claim decides everything |
| <Design agent or the same firm> | Locarno class, views, novelty statement | The render files | Views must be consistent; the agent will reject inconsistent ones |
| <Company secretary or CA> | Udyam registration, entity documents, assignments | The MCA portal | The concessional fee needs the certificate at filing |
| <Brand designer> | Source files, layered logo, assignment | The brand folder | Get the assignment with the invoice, every time |
| <Packaging printer> | Print-ready files and dates | The artwork folder | The print date is the disclosure date |
| <Marketplace brand registry desk> | Takedowns and brand protection enrolment | The seller panel | Enrolment needs the registration certificate |
| <Customs broker> | Recordal of marks with Indian Customs | The registration and the product list | Stops the import, not the listing |
| <Overseas associate counsel> | Madrid, PCT national phase, foreign FTO | WIPO or the agent's network | Fees are per country; quote ranges, never one number |
