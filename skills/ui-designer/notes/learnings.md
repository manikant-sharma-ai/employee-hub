# Learnings - ui-designer

1. **The states table is the deliverable, not the pretty screen.** Every build that came back wrong was missing a state, not a shadow.
2. **The developer's second question is the spec's first gap.** Log every question asked twice and put the answer in the template.
3. **360px, 200% zoom, longest string, second language** - four checks that catch most shipped layout bugs before they ship.
4. **Copy is design.** An empty state written by a developer reads like a database.
5. **A new spacing value is a decision, not a convenience.** If a screen needs 18px, the scale is wrong or the screen is.
