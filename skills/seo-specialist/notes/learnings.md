# Learnings

Durable rules, not stories. One line each, dated when it was learned. Read this at the start of every task.

- 2026-11-03 - Search Console queries at position 5-20 with high impressions are the cheapest wins available. Look there before building anything new.
- 2026-11-03 - Intent is read off the results page, never off the keyword's wording. A guide cannot rank for a query whose SERP is nine product pages.
- 2026-11-03 - One page per query cluster. A second page for the same query splits the signal and looks like instability.
- 2026-11-03 - Word count comes from the SERP average, not from a rule of thumb. Length is a consequence of coverage.
