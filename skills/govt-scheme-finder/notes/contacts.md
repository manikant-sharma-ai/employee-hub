# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <District Industries Centre officer> | State incentives, PMEGP routing, district eligibility | In person with the Udyam certificate | Ask for the name and a written reply; verbal is not approval |
| <State MSME / industries directorate> | Policy interpretation, window status, the clause in question | Email, quoting the clause | Keep every reply with a date |
| <Bank MSME desk / relationship manager> | CGTMSE, Mudra, the guarantee, the sanction | A written proposal | The bank files the guarantee, not the business |
| <CA> | Turnover and investment certification, project report, the UC | A specific question with the document | The UC signatory matters as much as the figures |
| <Sector nodal agency> | Sector scheme eligibility, claim queries | The portal's query route, with the application number | Keep the file number visible |
| <Export promotion council> | RCMC, MAI, market access, buyer meets | Membership first | Membership gates most export benefits |
| <DGFT regional office> | IEC, authorisations, RoDTEP queries | Portal, then the regional office | The IEC is the gate for everything export |
| <Consultant, if engaged> | Project report, follow-up, technical write-up | A written scope and a GST invoice | Never hand over portal credentials or originals |
| <Lawyer> | The agreement with the agency, an undertaking with liability | Before signing | This role does not sign |
| <Insurance agent> | Asset insurance where a scheme requires it | Before the claim | Some schemes condition disbursement on it |
