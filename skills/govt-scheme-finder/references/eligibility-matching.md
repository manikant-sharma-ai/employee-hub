# Eligibility matching

A scheme is a set of tests. The work is running them honestly against the business's own facts, and
writing down the evidence before a day is spent on an application.

## The eligibility grid

One row per scheme, one column per criterion, one cell per fact:

| Criterion | Test | Mark | Evidence |
|---|---|---|---|
| Constitution | Is the entity type allowed? | Met / Not met / Unverified | Certificate of incorporation or Udyam |
| Activity | Manufacturer, service or trader? | | Udyam activity, GST HSN/SAC |
| Scale | Which Udyam band, on the current limits? | | Udyam certificate, ITR, fixed asset schedule |
| Age | Is there a maximum or minimum age of the unit? | | Date of commencement of production |
| Turnover | Within the ceiling for the last N years? | | Audited financials, GST returns |
| Location | Is the state or district eligible? | | Registered address, DIC confirmation |
| Sector | Is the activity on the eligible list? | | NIC code, scheme annexure |
| Investment | Is the investment in the eligible category and window? | | Invoices, quotations, sanction date |
| Prior claim | Has another benefit been taken for the same purpose? | | Past sanction letters |
| Compliance | GST, PF, ESI, ITR filings current? | | Portal status, acknowledgements |
| Banking | Is the account regular, with no NPA? | | Bank statement, CIBIL, the lender's view |
| Undertaking | Can the founder sign the conditions? | | The scheme's conditions, read |

Rules: **no cell is left blank** - blank means unverified and must be marked as such. **Every "met"
has the document named**, because the portal asks for it. **One "not met" ends the row** - reject and
record the reason.

## The definitions that decide most cases

| Term | Why it decides | Ask |
|---|---|---|
| **Micro / small / medium** | Decides the scheme, the rate and the preference | Current Udyam band, on the revised investment and turnover limits |
| **Manufacturing vs service vs trade** | Traders are excluded from many benefits | The Udyam activity and the NIC code, not what the founder calls it |
| **New unit** | Most capital subsidies are for new units only | Is the unit new, or an expansion of an existing one? |
| **Expansion / diversification** | A separate category with a separate rate | The scheme's own definition of substantial expansion |
| **Date of commencement of production** | Starts the clock on several windows | The first sale invoice, or the statutory certificate |
| **Eligible fixed capital investment** | Often excludes land, and sometimes vehicles and furniture | The scheme's negative list |
| **Plant and machinery** | The base for capital subsidy and for Udyam classification | The fixed asset schedule, at cost, excluding second-hand where excluded |
| **Export turnover** | A separate test from total turnover | The shipping bills and the e-BRCs |
| **Women / SC-ST owned** | Unlocks sub-targets and, in places, a higher subsidy | Shareholding and management control, not the promoter's word |

The most expensive mistake in this file: a business describes itself as a manufacturer because it
assembles or repacks, and the scheme's definition requires a manufacturing process. Read the
definition, then ask what the GST registration and the Udyam entry actually say.

## Classification, checked properly

| Check | Where |
|---|---|
| Udyam certificate exists and is current | udyamregistration.gov.in |
| The band matches the last audited figures | The certificate versus the ITR and the fixed asset schedule |
| The activity is correctly recorded | Manufacturing, service, or both |
| The GSTIN is linked and active | The GST portal |
| Traders are flagged as such | Because the exclusion applies |

A business that crossed a band boundary needs the classification updated **before** applying, not
after: applying in the wrong band is a false declaration, and a recovery with interest.

## The disqualifiers, checked first

Run these before anything else, because each one ends the conversation:

| Disqualifier | Test |
|---|---|
| A trader claiming a manufacturing scheme | Activity mismatch |
| A defaulting borrower, or an NPA account | The lender's view |
| GST or ITR not filed for the last year | Compliance status |
| The same purpose already subsidised | Past sanction letters |
| The investment predates the sanction | Invoice dates against the application date |
| A unit in a state whose policy window has closed | The state's notification |
| A proprietary firm where the scheme requires a company | Constitution |
| Related-party transactions used to inflate turnover | The financials and the auditor's note |

## Ranking, once eligibility is clear

```
Value = (expected rupees) x (odds) / (person-days of effort + rupees of cost to apply)
```

| Scheme | Rupees | Odds | Person-days | Rank |
|---|---|---|---|---|
| State capital subsidy on machinery | 6,00,000 | 70% | 8 | 1 |
| CGTMSE-backed term loan (enables the purchase) | 40,00,000 loan | 60% | 3 | 2 |
| Quality certification reimbursement | 40,000 | 85% | 2 | 3 |
| Export market access for a fair | 1,20,000 | 40% | 6 | 4 |

Odds are a judgement, and the reasoning must be written: a first-time applicant in a district with a
functioning DIC is a better bet than a scheme with an unannounced window. Never present odds as a
measurement - they are an estimate with a reason attached.

## When a criterion is "unverified"

Three ways forward, in this order:

1. **Read the scheme's own guidelines** for the definition.
2. **Ask the office that administers it** - the DIC, the nodal agency, the bank's MSME desk - in
   writing, and keep the reply.
3. **Ask the CA** for the figure the scheme will test, such as turnover or investment.

Until one of those answers, the criterion stays unverified and the brief says so. An application
built on an unverified criterion is the most common reason a file is returned after three months.

## Anti-patterns

| Anti-pattern | Cost |
|---|---|
| Matching on the headline rate | The definitions disqualify, and the rate was never reachable |
| Leaving a cell blank | It is discovered at submission, with the file already prepared |
| Trusting the founder's own classification | "We are a manufacturer" is a legal statement, not a description |
| Ignoring the prior-claim test | Double-dipping triggers recovery |
| Ranking by rupees alone | A large scheme with 20% odds and 15 days of work is a worse use of time |
| Presenting odds as a probability from a model | It is an estimate; say so and give the reason |
| Applying while a compliance filing is pending | Most portals check the status and reject at the last step |
