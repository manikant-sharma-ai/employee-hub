# Application and documents

The application is a document exercise, and it fails on the document, not on the merit. This file is
the pack, the portals and the order.

## The document pack, assembled once

Most of this is reused across applications. Build it once, keep it current, and every later
application takes days instead of weeks.

| # | Document | Note |
|---|---|---|
| 1 | Udyam registration certificate | Current, with the correct activity and band |
| 2 | Certificate of incorporation, partnership deed or proprietorship proof | Constitution as the scheme requires |
| 3 | PAN, GST certificate, and the last 12 months of returns | Filing status must be clean |
| 4 | ITR and audited financials for the last 2-3 years | Signed by the CA; the turnover figure the scheme tests |
| 5 | Fixed asset schedule, at cost | The investment figure, with dates |
| 6 | Project report with the cost of the project and the means of finance | The core of a capital or a loan application |
| 7 | Machinery or equipment quotations, with specifications | Three where the scheme asks; on letterhead; dated |
| 8 | Land or premises documents - ownership, lease, or the industrial shed allotment | The location test |
| 9 | Statutory approvals - factory licence, pollution consent, fire, FSSAI, drug licence | Sector-specific |
| 10 | Bank statement for 6-12 months, and the sanction or the loan application | The lender's view |
| 11 | Electricity bill or connection proof, and the commencement certificate | Date of commencement of production |
| 12 | Undertakings - no prior benefit, employment generation, retention period | Read before signing; they are enforceable |
| 13 | Caste, gender or disability certificate, where a sub-target applies | For the reserved categories |
| 14 | NIC code and the HSN or SAC list | Consistency across Udyam, GST and the application |

**Consistency is the test.** Turnover on the Udyam certificate, the ITR, the GST returns and the
application must agree. A 5% mismatch is a query, and a query costs a month.

## The portals, and what each is for

| Portal | For | Note |
|---|---|---|
| Udyam registration | The base registration | Free; self-declared; update when the band changes |
| Startup India | DPIIT recognition, benefits, the fund route | Needs the innovation write-up, not just the incorporation |
| GeM | Selling to government | Separate seller registration, with catalogue and brand approval |
| DGFT | IEC, Advance Authorisation, EPCG | The IEC is the gate for every export benefit |
| State single-window or industries portal | State incentives, and often the application itself | Rules differ by state; the DIC is the human route |
| Bank's MSME portal | CGTMSE-linked and Mudra loans | The bank files the guarantee, not the business |
| KVIC / KVIB / DIC | PMEGP | Includes a training requirement before disbursal |
| The sector ministry's scheme portal | Technology upgradation, ZED, design, IPR | Windows open and close; check the current notice |

## The order of work, for a capital subsidy

| Step | Do | Time |
|---|---|---|
| 1 | Confirm eligibility and the application window | 1-2 days |
| 2 | Assemble the pack, with the CA certifying the figures | 3-5 days |
| 3 | Get the quotations and the project report finalised | 3-7 days |
| 4 | File the application **before** committing the expenditure | 1 day |
| 5 | Acknowledge, respond to queries, keep the file number | Ongoing |
| 6 | Wait for the sanction or the in-principle approval | 1-6 months |
| 7 | Buy, install, commission, and keep every invoice in the eligible category | As per plan |
| 8 | File the claim with the invoices, the payment proof and the commissioning certificate | 1-2 weeks |
| 9 | Receive the disbursement, then file the utilisation certificate | As per the scheme |
| 10 | Keep the records for the retention period | 5 years or as stated |

The single rule that saves the most money: **the application comes before the purchase.** A machine
bought first and applied for later is, in most capital schemes, simply not eligible.

## Who signs what

| Document | Signed by |
|---|---|
| Application form | The authorised signatory of the entity |
| Project report and financials | The CA, with the UDIN where required |
| Undertakings and declarations | The promoter or the authorised signatory, personally where asked |
| Bank sanction and guarantee documents | The lender and the promoter |
| Utilisation certificate | The CA, and the promoter |
| Any agreement with the agency | The authorised signatory, after `legal-drafter` and the lawyer have read it |

This role assembles and checks the pack. It does not sign, and it does not certify a figure.

## The consultant question

| Engagement | Fair | Not fair |
|---|---|---|
| A fixed fee for preparing the file and the project report | Reasonable, and it is verifiable work | - |
| A success fee on sanction | Common, and should be a modest percentage with a written scope | A large percentage of the sanction for work the founder could file free |
| A "guaranteed sanction" | Never | A guarantee is a fraud signal |
| Payment into a personal account, no invoice | Never | Always |
| Handing over the original documents and the portal credentials | Never | The founder keeps the login and the originals |

Rule for the brief: state plainly that **the application can be filed by the founder at no cost on
the official portal**, and that a consultant is being paid for time and expertise, not for access.

## Anti-patterns

| Anti-pattern | Cost |
|---|---|
| Assembling the pack per application | Weeks of work that a reusable pack removes |
| Figures that disagree across documents | A query that costs a month, or a rejection |
| Applying after the purchase | The benefit is gone, and the money is spent |
| Signing an undertaking nobody read | A retention or employment condition that is later breached |
| Giving originals and portal credentials to a consultant | No visibility, and no control of the file |
| Missing the query deadline | Most schemes close the file silently |
| No file number or acknowledgement kept | No way to follow up, and no proof of filing |
