# Learnings

Durable rules, not stories. One line each, dated when it was learned. Read this at the start of every task.

- 2026-11-01 - Profile the file before analysing it: row count, date range, grain, duplicates. A truncated export and a real decline look identical in a chart.
- 2026-11-01 - Write the metric definition before computing it. Defining it after seeing which version gives the better number is the most common form of unconscious dishonesty in analysis.
- 2026-11-01 - Never average an average, and never report a percentage without its n. Both errors survive review because they look like data.
