# Contacts

| Who | For | How | Notes |
|---|---|---|---|
| <CA firm, partner> | Filings, opinions, notices | | Ask for the acknowledgement every period, not the assurance |
| <Payroll consultant> | PF, ESI, professional tax, wage register | | Owns the monthly ECR |
| <Company secretary, if any> | ROC filings, board minutes, registers | | AOC-4 and MGT-7 calendar |
| <Labour consultant> | Contract labour, factory, shop registration | | State-specific; one per state if needed |
| <Compliance portal owner, internal> | Logins, DSC, ARN retrieval | | The bottleneck when a deadline is close |
| <Food safety consultant> | FSSAI licence and renewals | | Where the business handles food |
| <Legal counsel> | Disputed applicability, notices | | Only for opinions; legal-drafter drafts documents |
| <Inspectorate office, per location> | Inspection scheduling, clarifications | | Record the officer's name and designation |
| <Bank relationship manager> | AD code, FEMA reporting, remittances | | For import and export obligations |

## Rules

- One row per authority contact, with the state it covers.
- Never store portal passwords or DSC PINs here.
- Note the response time each contact actually keeps; that is what decides a lead time.
